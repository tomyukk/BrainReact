## 1. Опис проєкту

BrainReact — невеликий комерційний (за умовою завдання) вебзастосунок для перевірки швидкості реакції, створений як демо-модуль міні-ігор платформи Brain-1. Користувач натискає «Старт», чекає, поки поле стане зеленим, і клацає якомога швидше. Застосунок зберігає 5 останніх результатів у `localStorage` і запускає анімацію конфеті при новому рекорді.

Запуск: відкрити `index.html` у браузері (збирання та сервер не потрібні).
